# **App Name**: FluxoFacil

## Core Features:

- Dashboard Overview: Interactive dashboard presenting key financial metrics and summaries.
- Transaction Categorization: Categorize transactions to track spending habits.
- Manual Transaction Entry: Allow users to input transactions with details like date, amount, and category. The ability to tag is included.
- AI Category Suggestions: AI tool to suggest transaction categories.

## Style Guidelines:

- Primary color: Cyan (#00FFFF) to evoke calmness and clarity, contrasting well within a light interface.
- Background color: Very light gray (#F5F5F5), providing a clean and neutral backdrop for content.
- Accent color: A complementary teal (#008080) for interactive elements, drawing the user's eye without overwhelming the palette.
- Clean and modern typography to ensure readability.
- Clean layout and use of white space to focus on data.
- Consistent and simple icons that easily explain the type of transactions or the state of some elements.
